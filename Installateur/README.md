# Installateur officiel du SEPO

Ce dossier contient les scripts permettant d’installer et de mettre à jour l’architecture technique du SEPO.

## Règles

- Aucun script ne doit supprimer un document existant sans validation humaine.
- Aucun script ne doit prétendre avoir exécuté une action non vérifiée.
- Chaque version doit être testée avant d’être déclarée stable.
- Google Drive conserve les documents.
- GitHub conserve les scripts et leur historique.
